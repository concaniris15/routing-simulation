# routing-simulation

A repository containing network simulation and router configuration activities using Cisco Packet Tracer.

## 📂 Repository Contents

* **`router (1).pkt`**: Cisco Packet Tracer network simulation file featuring router configuration, subnetting, and end-to-end device connectivity.

## 🛠️ Tools & Technologies Used

* Cisco Packet Tracer
* Networking Protocols & Subnetting

## 🚀 Getting Started

1. Download and install [Cisco Packet Tracer](https://www.netacad.com/courses/packet-tracer).
2. `router (1).pkt` file.

3. Open the file inside Cisco Packet Tracer to view the network topology and configurations.
